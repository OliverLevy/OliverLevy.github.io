Password Key

Plug in the key, then click Connect.

Passwords

Click a name to rename it (press Enter to save). Reveal and Delete need a hold on the key.

Add a password

Generated passwords are created on the key and never pass through this page. Importing needs a hold on the key. A new password becomes the active one.

Settings

Changes save on the key right away.

Test typing

Check that every symbol comes out right on your keyboard layout, then clear the box.
